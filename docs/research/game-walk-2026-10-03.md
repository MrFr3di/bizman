## 4. New protocol facts

1. **First-class error surfaces.** The game serves its own 404 pages from
   `/err/404/` (7 requests, `Content-Length` 15,910) and `/err/popup404/`
   (2 requests, 817 bytes), both with HTTP status 404. No dataset recorded them.
2. **`/empty` and `/empty.html` are distinct.** `/empty.html` returns 26 bytes and
   was already in the asset census; `/empty` was observed separately in this session.
3. **Server-side parameter validation is publicly observable.** Requesting
   `/company/financechart/`, `/company/moneytransfer`, `/company/notepad` or
   `/city/object/` without `?id=` returns an unhandled Java stack trace
   (`ru.plazma.framework.ValidationException: Param id required`,
   `ru.biz4fun.web.components.PopupPage`). These surfaces therefore require `id`,
   and the route patterns in `knowledge/http/routes` are wrong where they omit it.
4. **Route patterns that are not real routes.** `/world/country/?id=` and
   `/world/region/?id=` return the game's own 404 page; `/units/division/` and
   `/market/` return HTTP 404; `/units/instantsale/` and
   `/user/payment/specialpacks2/` return HTTP 403 to an anonymous request.
5. **Unit type identity confirmed from a live title.** Unit `13548` renders as
   "Сеть магазинов одежды", which matches the `shop.apparel` type referenced in
   captured route patterns. The corpus only had the generic `shop` subtype.
